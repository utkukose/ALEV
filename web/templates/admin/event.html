🚀 Getting Started
1
RPG / Roles — Define attributes (Strength, Intelligence etc.) and member roles
2
Scenario — Create the game flow and stages
3
Tasks — Add tasks linked to scenarios
4
Teams — Create teams, let members join with invite code
5
Activate — Publish the event
✨ RPG Attributes
Define traits like Strength, Intelligence, Eco. Use their keys in task rewards: {"strength": 2, "intel": 1}
⚔️ Roles
Each member picks a role on joining. The role sets starting attributes and bonus multipliers.
🗺️ Scenario & Tasks
A scenario defines the game flow. Tasks are linked to scenarios. Members use /tasks to list them and /submit ID link to complete them.
When a scenario activates, Telegram groups are notified automatically.
👥 Teams & Approvals
Teams join via web or Telegram with /join CODE. When a member submits a task it appears in Approvals — approve it to add SP automatically.
📢 Announcement
Send Telegram messages to all groups or selected teams. Delivered with emoji based on type: info, warning or success.
Once a bot is added, all actions are relayed to Telegram groups.
